我注意到您请求的是关于 “Codex” 的指令详解，但在人工智能和编程领域有几个不同的 “Codex”：

  1. OpenAI Codex: 这是一个由 OpenAI 训练的模型，是 GitHub Copilot 等代码生成工具的底层技术。它本身没有 “指令” (commands)，而是接受自然语言描述或代码上下文来生成代码。
  2. 您是否是指 claude-code? 因为在上一轮对话中我们讨论了 claude-code 的指令。

请您明确指出您指的是哪个 “Codex”，或者确认您是否想让我继续讲解 claude-code 的指令。

如果您指的是 OpenAI Codex 模型，我可以提供一份关于如何有效与该模型交互（即提示工程，Prompt Engineering）的详细说明，但它不会是像 CLI 工具那样的“指令”列表。
